# Homebrew tap for ThockBox

[ThockBox](https://github.com/Bruno-Alumn/ThockBox) plays mechanical keyboard
sounds as you type. Install it with:

```sh
brew install --cask bruno-alumn/thockbox/thockbox
```

ThockBox updates itself from new releases. The cask here comes from
`packaging/thockbox.rb` in the main repository.
